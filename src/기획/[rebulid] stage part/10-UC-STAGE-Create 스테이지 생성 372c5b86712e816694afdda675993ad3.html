10-UC-STAGE-Create 스테이지 생성

1. 메타정보

항목내용
UC ID10-UC-STAGE-Create
목표운영자가 새로운 스테이지를 생성한다
액터관리자

우선순위P0

2. 정상 플로우

  1. 관리자가 스테이지 관리 > 스테이지 생성 진입
  1. 기본 정보 입력: 이름, 총 회차, 회차별 납입금, 모집 인원, 모집 기간, 지급 순번 방식
  1. 참여 조건 설정: i-CSS 최소 등급, 연령 제한
  1. 쿠폰 적용 설정
  1. 유효성 검증
  1. 스테이지 생성 → 상태: DRAFT
  1. 모집 공개 시 → RECRUITING 전환

3. 대안/예외 플로우

#조건처리
5a필수값 누락해당 필드 오류 표시
5b모집 인원 < 최소 운영 인원유효성 오류
7a임시 저장(DRAFT) 선택DRAFT 상태로 저장
[7a] DRAFT 상태 스테이지는 회원에게 노출 안 됨

4. 비즈니스 룰

BR#내용
BR-01생애주기: DRAFT → RECRUITING → CLOSED → IN_PROGRESS → ENDED → DELETED

BR-03지급 순번 방식: 추첨(RANDOM) / 선착순(FCFS) / 관리자 지정(MANUAL)
BR-04i-CSS 최소 등급 미달 회원은 참여 불가
