34-UC-DEFAULT-SafeService 안심서비스 선택

1. 메타정보

항목내용
UC ID34-UC-DEFAULT-SafeService
목표상환 불이행 회원이 '안심서비스'를 사용하여 상환을 은행 대출로 전환한다
액터사용자
상태작성중
트리거상환 불이행 안내 후 회원이 '안심서비스' 선택
우선순위P1

2. 정상 플로우

  1. 안내 화면에서 '안심서비스' 선택
  1. 안심서비스 조건 확인 (대출 한도, 금리 등)
  1. 은행 대출 신청 연계 (isLocc API 또는 제휴 기관)
  1. 대출 승인 시 대납금 상환 완료
  1. 대출 제도로 전환, 월 납부 시작
