설치 가이드 · Setup Guide

Figma Design Agent 설치 및 실행

새 컴퓨터에서 이 저장소를 설치해 디자인 생성을 시작하기까지의 전 과정입니다. 먼저 공통 준비를 마친 뒤, 본인 OS 탭(macOS / Windows)을 따라 진행하세요.

0공통 사전 준비 (Mac · Windows 모두)

OS별 자동 설치 스크립트를 돌리기 전에, 아래 3가지를 먼저 갖춰야 합니다. (이 항목들은 자동 스크립트가 설치해 주지 않습니다.)

준비물용도 / 설치
Git저장소 클론용. git --version 으로 확인. 없으면 git-scm.com (Windows) / Mac은 자동 스크립트가 Xcode CLT로 함께 설치.
Figma 데스크톱 앱브라우저 버전 아님. 플러그인 개발 모드 실행에 데스크톱 앱이 필요. figma.com/downloads
Claude Code CLI터미널에서 AI가 요구사항을 해석·생성하는 진입점. 설치: npm install -g @anthropic-ai/claude-code (또는 사내 배포 방식). 로그인 필요.

저장소 클론

# 작업할 폴더에서
git clone <저장소 URL> figma-design-agent
cd figma-design-agent
전체 흐름 미리보기. ① 공통 준비 → ② OS별 자동 설치 스크립트 → ③ 브리지 기동 → ④ Figma에 플러그인 등록·실행 → ⑤ 연결 확인 → ⑥ 디자인 생성 준비(기획 학습) → ⑦ 생성 시작. ③~⑦은 두 OS 공통이며 각 탭 하단에 정리돼 있습니다.

1OS별 설치 — 본인 OS를 선택하세요

macOS 사용자 페이지

1단계 · 패키지 매니저(Homebrew) 확인

자동 스크립트가 Homebrew를 비대화식으로 설치 시도합니다. 설치 중 sudo(관리자) 암호 입력을 요청할 수 있습니다. 만약 자동 설치가 실패하면 아래로 수동 설치 후 다시 진행하세요.

# (자동 실패 시에만) Homebrew 수동 설치
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2단계 · 자동 설치 스크립트 실행

저장소 폴더에서 아래 한 줄을 실행합니다. 멱등(이미 설치된 건 건너뜀)·비대화식이라 중간에 묻지 않고 끝까지 진행됩니다. 출력의 [OK] 라인들을 확인하세요.

bash scripts/setup-mac.sh

스크립트가 자동 처리하는 항목

항목내용
1. HomebrewMac 패키지 매니저 (없으면 비대화식 설치)
2. Python 3시스템 python3(3.9+) 우선, 없으면 brew install python@3.12
3. Python 패키지requests, Pillow (PEP 668 환경은 --break-system-packages→--user 폴백)
4. Node.js LTSHomebrew로 설치 (18+ 필수)
5. npm 의존성npm install --legacy-peer-deps
6. sharp 네이티브 모듈Apple Silicon=darwin-arm64 / Intel=darwin-x64 (uname -m로 자동 판단)
7. 프로젝트 빌드npm run build → out/
8. 산출물 정리생성 7일 경과 임시 산출물 자동 삭제
macOS 참고. Apple Silicon은 Homebrew 경로가 /opt/homebrew, Intel은 /usr/local 입니다(스크립트가 자동 판단). macOS는 기본 UTF-8이라 별도 한글 설정 불필요. 스크립트 종료 시 출력되는 Python 경로를 기억해 두세요(보통 python3 로 충분).

3단계 · 브리지 서버 기동

이 터미널은 켜둔 채로 유지하세요(브리지가 계속 떠 있어야 함). 새 터미널 탭에서 이후 단계를 진행합니다.

npm run bridge

아래 두 로그가 보이면 정상입니다.

[FigmaWS] Server listening on port 8767
[MCP] HTTP server listening ...

4단계 · Figma 데스크톱에 플러그인 등록·실행

  1. Figma 데스크톱 앱을 엽니다(아무 디자인 파일 또는 새 파일).
  2. 상단 메뉴 Plugins → Development → Import plugin from manifest…
    (또는 캔버스 우클릭 → Plugins → Development → Import plugin from manifest…)
  3. 파일 선택창에서 figma-design-agent/src/figma-plugin/manifest.json 을 선택합니다.
  4. 등록 후 Plugins → Development → "Figma Design Agent" 를 실행합니다.
  5. 플러그인이 ws://localhost:8767 로 브리지에 자동 연결됩니다. 브리지 터미널에 Figma: connected 가 뜨면 성공.
플러그인 이름은 정확히 "Figma Design Agent" 입니다.

5단계 · 연결 확인

python3 scripts/figma_mcp_client.py init

Ready. 와 실제 세션 ID가 나오면 성공입니다. (Session initialized: None 이면 브리지 미기동 또는 플러그인 미연결.)

6~7단계 · 디자인 생성 준비 및 시작

이제 터미널의 Claude Code CLI에서 진행합니다. 자세한 순서는 아래 "공통 — 디자인 생성 시작" 섹션을 참고하세요.

Windows 사용자 페이지

1단계 · 패키지 매니저(winget) 확인

자동 스크립트는 winget으로 Python·Node를 설치합니다. PowerShell에서 winget --version 으로 확인하세요. 없으면 Microsoft Store에서 "앱 설치 관리자"(App Installer) 를 설치하면 winget이 활성화됩니다.

2단계 · 자동 설치 스크립트 실행

PowerShell을 열고 저장소 폴더에서 아래를 실행합니다. 멱등·비대화식이라 끝까지 자동 진행됩니다.

powershell -ExecutionPolicy Bypass -File scripts\setup-windows.ps1

스크립트가 자동 처리하는 항목 (7단계 + 정리)

항목내용
1. Python 3.12winget으로 설치 (figma_mcp_client.py 실행용, 3.9+ 필요)
2. Python 패키지requests, Pillow
3. PYTHONUTF8=1사용자 환경변수 등록 — 없으면 한글 출력이 cp949 오류
4. Node.js LTSwinget으로 설치 (18+ 필수, 구버전이면 자동 업그레이드)
5. npm 의존성npm install --legacy-peer-deps
6. sharp 네이티브 모듈@img/sharp-win32-x64 플랫폼 패키지
7. 프로젝트 빌드npm run build → out\
8. 산출물 정리생성 7일 경과 임시 산출물 자동 삭제
Windows 함정 (스크립트가 처리하지만 참고).
  • PATH의 python3/python은 Microsoft Store 별칭 stub입니다 — 실제 Python은 %LOCALAPPDATA%\Programs\Python\Python3xx\python.exe. figma_mcp_client.py 호출 시 이 전체 경로 + PYTHONUTF8=1 환경변수를 사용합니다.
  • winget 설치 직후 같은 PowerShell 세션은 PATH가 갱신 안 됨 — node/npm이 안 잡히면 C:\Program Files\nodejs\ 전체 경로 사용(스크립트가 자동 처리).
  • 스크립트 종료 시 출력되는 Python 전체 경로를 기억해 두세요.

3단계 · 브리지 서버 기동

이 PowerShell 창은 켜둔 채로 유지하세요. 새 창에서 이후 단계를 진행합니다.

npm run bridge

아래 두 로그가 보이면 정상입니다.

[FigmaWS] Server listening on port 8767
[MCP] HTTP server listening ...

4단계 · Figma 데스크톱에 플러그인 등록·실행

  1. Figma 데스크톱 앱을 엽니다(아무 디자인 파일 또는 새 파일).
  2. 상단 메뉴 Plugins → Development → Import plugin from manifest…
  3. 파일 선택창에서 figma-design-agent\src\figma-plugin\manifest.json 을 선택합니다.
  4. 등록 후 Plugins → Development → "Figma Design Agent" 를 실행합니다.
  5. 플러그인이 ws://localhost:8767 로 자동 연결됩니다. 브리지 창에 Figma: connected 가 뜨면 성공.
플러그인 이름은 정확히 "Figma Design Agent" 입니다.

5단계 · 연결 확인

Windows는 실제 Python 전체 경로 + UTF-8 설정으로 호출합니다(Python3xx는 실제 버전으로 치환).

# PowerShell
$env:PYTHONUTF8=1
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" scripts\figma_mcp_client.py init

Ready. 와 실제 세션 ID가 나오면 성공입니다.

6~7단계 · 디자인 생성 준비 및 시작

이제 터미널의 Claude Code CLI에서 진행합니다. 아래 "공통 — 디자인 생성 시작" 섹션을 참고하세요.

2공통 — 디자인 생성 시작

설치·연결이 끝나면, 실제 디자인 생성은 터미널의 Claude Code CLI에서 대화로 진행합니다. 가장 쉬운 방법은 아래 한마디입니다.

  1. "디자인 생성 준비" 라고 입력
    Claude Code CLI가 OS를 자동 판단해 환경 설정 → 브리지 → 연결 확인 → 플러그인 안내 → 기획 문서 전체 학습(통독)까지 자동으로 진행합니다. (플러그인 실행만 수동 — 안내가 나오면 Figma에서 "Figma Design Agent"를 실행하세요.)
  2. 기획 문서 통독 완료를 기다립니다
    서비스 맥락(유스케이스)을 완전히 학습해야 디자인 품질이 보장됩니다. 이 단계가 끝나야 빌드 게이트를 통과합니다.
  3. 디자인을 요청합니다
    예: "메인화면 그려", "지금 선택한 와이어프레임으로 디자인 생성해". 요구사항(PRD)·와이어프레임을 함께 주면 더 정확합니다.
  4. 결과 확인
    Figma 파일에 디자인 시스템(색·컴포넌트·텍스트 스타일)이 바인딩된 화면이 생성됩니다.
핵심 순서 요약. 환경 설정(스크립트) → npm run bridge(켜둔 채 유지) → Figma에서 플러그인 실행 → … init 으로 연결 확인 → Claude Code CLI에 "디자인 생성 준비" → 디자인 요청.

!문제 해결 (자주 묻는 상황)

증상원인 / 해결
Session initialized: None 브리지 미기동 또는 플러그인 미연결. ① npm run bridge가 떠 있는지, ② Figma에서 "Figma Design Agent" 플러그인이 실행 중인지 확인.
브리지 로그에 Figma: connected 가 안 뜸 Figma 데스크톱 앱에서 플러그인을 실행해야 함(브라우저 버전 불가). Plugins → Development → Figma Design Agent.
Win 한글이 cp949 UnicodeEncodeError PYTHONUTF8=1 환경변수 누락. 스크립트가 등록하지만, 수동 호출 시 $env:PYTHONUTF8=1 을 먼저 실행.
Win python/node 명령을 못 찾음 설치 직후 같은 세션은 PATH 미갱신. PowerShell을 새로 열거나 전체 경로 사용 (%LOCALAPPDATA%\Programs\Python\…, C:\Program Files\nodejs\).
Win winget이 없음 Microsoft Store에서 "앱 설치 관리자"(App Installer) 설치 후 재실행.
Mac Homebrew 자동 설치가 멈춤 sudo 암호 입력이 필요한 경우. 위 macOS 1단계의 수동 설치 명령으로 설치 후 재실행.
Mac pip install 권한/환경 오류 최신 macOS의 PEP 668 제약. 스크립트가 --break-system-packages→--user로 자동 폴백하므로 스크립트를 재실행.
빌드 직후 색·텍스트 스타일이 안 입혀짐 빌드 도중 타임아웃 가능. … post-fix <rootId> 또는 … apply-text-styles <rootId> 로 보완(자동 복구도 동작).

설치가 정상인지 빠른 체크

  • 저장소 폴더에 out/ 가 생성됨 (빌드 성공)
  • npm run bridge 로그에 포트 8767·8769 리스닝 표시
  • Figma 브리지 로그에 Figma: connected
  • … init 실행 시 Ready. + 세션 ID 출력
