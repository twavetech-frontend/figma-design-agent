├─ scripts/design_rules/        룰 엔진 R-시리즈
├─ scripts/hooks/               통독·레퍼런스 커버리지 훅

ds/ 는 산출물

⚙️ design_rules/

R23(컴포넌트 스왑) · R59(타이틀 정렬) · R60(탭 인스턴스) · R63(섹션 차별화) 등 — 각 룰이 lint→inject→post-fix→verify 4단을 가짐.

🧹 산출물 수명주기

blueprint json 은 빌드 직후 자동 삭제, QA 스크린샷·레퍼런스 썸네일은 작업 종료 시 정리, 나머지는 7일 TTL.

03 · 디자인 생성 프로세스

"메인화면 그려" 한마디가 화면이 되기까지

01

04
Blueprint 작성

레퍼런스에서 본 패턴으로 JSON 명세를 새로 작성. 콘텐츠는 고정, 레이아웃·액센트는 자유.

04 · 하드 게이트

모델을 믿지 않는다,
코드가 강제한다

프로세스는 2층입니다 — 코드가 실행하는 단계와 모델이 자율로 하는 단계. 자율 단계는 조용히 건너뛰어질 수 있어, 훅이 커버리지를 추적하고 게이트가 빌드를 차단합니다.

📚 기획 통독 게이트

digest 맨 끝에만 있는 토큰으로 ack — 끝까지 읽어야만 통과. 문서 변경 시 fingerprint 가 ack 를 무효화.

_enforce_planning_read_gate · exit 2

🖼 레퍼런스 Read 게이트

Step A.0 이 검색한 썸네일을 이 세션에서 Read 했는지 PostToolUse 훅 기록으로 검증. 미Read 시 빌드 차단.

_enforce_reference_read_gate · 0-G

📸 Self-verify 게이트

빌드가 export 한 QA 섹션을 재export+Read 하고 체크리스트를 채웠는지 검증 — 미완료 상태로 다음 빌드 불가.

_enforce_selfverify_gate · 0-F

05 · BLUEPRINT

화면의 단일 명세, JSON 한 장

{
  "name": "imin_signup_home",
  "fill": "$token(bg-primary)", // 절대 규칙 0
  "_wireframeContent": { ... }, // 콘텐츠 1:1 게이트
  "references": [ ... ], // 실제 본 레퍼런스 기록
  "children": [
    { "name": "추천 스테이지", "_band": true },
    { "type": "instance",
      "componentKey": "19c3ba…", // DS 버튼
      "instanceProperties": { "Size": "lg" } },
    { "name": "ic-circle", "_keepSizing": true }
  ]
}

$token(...) 참조

색·spacing·radius 를 리터럴이 아닌 DS 토큰으로 선언 — 빌드가 Figma 변수에 바인딩.

의도 마커

_band(중요 섹션 풀폭 밴드) · _keepSizing(작성자 사이징 보호) · _segLabels(탭 라벨) · _ctaKeepPrimary(CTA 위계) — 마커 하나로 enforcer 체인이 자동 처리.

DS 컴포넌트는 인스턴스로

버튼·탭바·체크박스·페이지네이션은 raw frame 금지 — componentKey 로 직접 import, 색은 variant 가 제어.

08 · 디자인 시스템 바인딩

픽셀이 아니라 토큰으로 칠한다

빌드 후 색 · spacing · radius · 텍스트 스타일 · 아이콘 색이 전부 Imin DS 변수에 자동 바인딩됩니다. 이 덱의 모든 색이 바로 그 토큰입니다.

#7700ffbg-brand-solid
#f4ecffbg-brand-primary
#2c3744text-primary
#687079text-secondary
#f3f4f6bg-secondary
#d2d6dbborder-primary

Spacing → spacing-*

0/4/8/12/16/20/24/32… 스케일 값만 시맨틱 토큰에 바인딩. primitive 금지.

Radius → radius-*

4코너 개별 바인딩, 999는 radius-full. radius>0 이면 clipsContent 강제.

Type → Pretendard

DS 텍스트 스타일을 import 해 바인딩 — 크기 변경도 스타일 교체로(바인딩 절대 보존).

09 · 철학

같은 와이어, 매번 다른 디자인

와이어프레임은 콘텐츠 소스일 뿐 레이아웃 명세가 아닙니다(절대 규칙 0-C). 결정형 생성기는 fallback 으로 강등 — 비주얼은 매 세션 레퍼런스를 읽고 새로 도출합니다.

금지 — 와이어 1:1 복제

회색 박스 배치 그대로 옮기기 · 같은 폰트 크기 위계 · 와이어의 포인트 컬러 복사 · 인접 섹션을 같은 카드 패턴으로(0-N). "디자인이 아니라 와이어 강화"가 된다.

의무 — 창의적 재해석

핵심 수치는 hero 타이포 · 카드 그룹핑으로 위계 차등 · 브랜드 퍼플은 의미 있는 단일 액센트("나의 것"·주 CTA·키워드) · 레퍼런스에서 본 실제 패턴 차용을 references[] 에 기록.

예: 같은 신규가입 홈도 세션마다 — 한도 조회를 회색 pill 버튼으로, 출석/초대를 단일 카드 2행으로, "3,523명"만 퍼플 키워드 강조로 다르게 그려진다.

10 · 검증과 마무리

완료 보고 전, 스스로 의심한다

QA1
결정적 검사 (코드)

WCAG 대비 · 데드밴드 · 텍스트 무결성 · 와이어 콘텐츠 매치율 · 레이아웃 스멜 3종(분배 깨짐/wrap/폭 붕괴).

QA2
시각 검증 (모델)

섹션별 PNG 재export → Read → 체크리스트 12항목 PASS/FAIL/NA + 증거 인용. FAIL 은 즉시 live-fix.

QA3
정리

blueprint 자동 삭제(0-R) · QA 스크린샷/썸네일 cleanup(0-F-2) — 레포엔 소스만 남는다.

요약 — 이 에이전트가 특별한 이유
